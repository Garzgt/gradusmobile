# Landing Page Navigation Structure

This document defines the public navigation model for the GRADUS landing page.

## 1. Primary Header Navigation

Top-level links:
1. Home
2. Features
3. Roles
4. Team
5. Achievers
6. FAQ
7. Contact

Primary actions:
1. Open Web System
2. Download Desktop App
3. Get Mobile App

## 2. Anchor Mapping

Use smooth in-page anchors:
1. Home -> Hero
2. Features -> Timeline and Modules
3. Roles -> Role-Based Experience section
4. Team -> Developer Team Showcase section
5. Achievers -> Public Academic Achievers section
6. FAQ -> FAQ section
7. Contact -> Footer contact block

## 3. Mobile Navigation Rules

1. Use a right-side or full-screen menu panel.
2. Keep top actions visible with large touch targets.
3. Provide one-tap close and clear active state.
4. Keep CTA buttons accessible without deep scrolling.

## 4. Scroll Behavior

1. Header starts transparent over hero.
2. Header becomes solid after threshold.
3. Active link updates based on visible section.
4. Return-to-top action appears after long scroll.

## 5. Footer Quick Navigation

Footer quick links:
1. Features
2. Roles
3. Team
4. Achievers
5. FAQ
6. Contact Support
7. Privacy and Policy

## 6. Navigation Content Rules

1. Keep link labels short and user-friendly.
2. Avoid internal technical module names in public navigation.
3. Keep link order stable between desktop and mobile.
4. Ensure keyboard access for all navigation items.
