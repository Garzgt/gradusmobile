# GRADUS Landing Page Feature Catalog

This document lists all recommended public landing page features for GRADUS.

## 1. Product Story Features

1. LPF-001: Value-first hero headline
- Explain GRADUS value in one sentence.

2. LPF-002: Trust subtitle
- Mention scheduling, enrollment, grading, and recognition clearly.

3. LPF-003: Hero visual proof
- Use dashboard mockup or short loop preview.

4. LPF-004: Social proof strip
- Show pilot metrics, schools served, or adoption signals.

## 2. Conversion Features

1. LPF-005: Triple primary CTA set
- Open Web System
- Download Desktop App
- Get Mobile App

2. LPF-006: Sticky CTA behavior on mobile
- Keep actions reachable while scrolling.

3. LPF-007: Final CTA band
- Repeat core actions at page end with high contrast.

4. LPF-008: Contact and support CTA
- Let users ask questions without leaving the page.

## 3. Platform Access Features

1. LPF-009: Web app card
- Include role scope and open action.

2. LPF-010: Desktop app card
- Include version, OS support, and file size.

3. LPF-011: Mobile app card
- Include Android and iOS links.

4. LPF-012: QR quick-install block
- Direct mobile install access.

5. LPF-013: Release status badges
- Available, Beta, or Coming Soon.

## 4. Product Explanation Features

1. LPF-014: How GRADUS Works timeline
- 4-step process from scheduling to recognition.

2. LPF-015: Core modules showcase
- Scheduling Engine
- Enrollment Workflow
- Grade Management
- Academic Recognition

3. LPF-016: Role switcher panel
- Super Admin, Program Coordinator, Teacher, Student.

4. LPF-017: Governance highlight cards
- Deterministic rules
- Auditability
- Approval ownership

## 5. Public Academic Features

1. LPF-018: Academic achievers leaderboard section
- Public ranking block with policy-safe data.

2. LPF-019: Term filter for achievers
- Select term and academic year.

3. LPF-020: Program filter for achievers
- Show ranking by program or all programs.

4. LPF-021: Last updated metadata
- Display publication date and source.

5. LPF-022: Criteria transparency link
- Explain ranking and recognition rules.

## 6. Trust and Engagement Features

1. LPF-023: Campus testimonials or feedback
- Show 2 to 4 short role-labeled quotes.

2. LPF-024: Outcome cards
- Show process improvements if quotes are unavailable.

3. LPF-025: FAQ accordion
- Address top user concerns quickly.

4. LPF-026: Support channel block
- Email, contact form, and response expectations.

## 7. Navigation and Information Features

1. LPF-027: Sticky header navigation
- Features, Roles, Achievers, FAQ, Contact.

2. LPF-028: Active section indicator
- Show where the user is in page flow.

3. LPF-029: In-page anchor links
- Jump to deep sections smoothly.

4. LPF-030: Footer quick links
- Platform links, support, policy links, and domain identity.

## 8. Visual and Motion Features

1. LPF-031: Section reveal animation
- Soft fade and rise with short duration.

2. LPF-032: Intentional hover states
- Cards and CTAs communicate interactivity.

3. LPF-033: Ambient background motion
- Subtle gradients or shapes, never distracting.

4. LPF-034: Reduced-motion support
- Maintain usability with minimal movement.

## 9. Accessibility Features

1. LPF-035: Keyboard-first navigation
2. LPF-036: Visible focus states
3. LPF-037: Semantic heading order
4. LPF-038: Alt text on informative media
5. LPF-039: High contrast token usage
6. LPF-040: Touch target minimum 44 x 44

## 10. Performance and Technical Features

1. LPF-041: Responsive images and media
2. LPF-042: Lazy loading for non-critical assets
3. LPF-043: Lightweight motion implementation
4. LPF-044: Mobile-first layout strategy
5. LPF-045: SEO-ready metadata and Open Graph tags
6. LPF-046: Structured data for software application

## 11. Analytics Features

1. LPF-047: CTA click tracking
2. LPF-048: Scroll-depth tracking per section
3. LPF-049: Platform-card interaction tracking
4. LPF-050: FAQ interaction tracking

## 12. Image and Developer Team Features

1. LPF-051: High-density image storytelling
- Keep strong visual narrative using real UI screenshots and institutional photos.

2. LPF-052: Performance-safe image loading strategy
- Load critical hero and platform images first and lazy-load deeper sections.

3. LPF-053: Dedicated Developer Team showcase section
- Display official team members with formal photos and role labels.

4. LPF-054: Team member profile cards
- Include full name, role, specialization, and contribution summary.

5. LPF-055: Team grouping and filtering
- Support grouping by function (Core, Frontend, Backend, Mobile, QA).

6. LPF-056: Portrait quality and consistency rules
- Maintain consistent crop, lighting, attire, and visual card treatment.

7. LPF-057: Team profile detail interaction
- Expand card or open modal for full member details and links.

8. LPF-058: Image governance and consent metadata
- Keep approved source, consent state, and attribution notes for public photos.

3. LPF-035 to LPF-046
4. LPF-051 to LPF-056

Priority P2 (strongly recommended):

2. LPF-031 to LPF-034
3. LPF-047 to LPF-050
4. LPF-057 to LPF-058
