This folder stores sample exports and images used as style references for generated schedule outputs.

8. Sample_courseTable.png

## Usage

1. Use these files to match visual layout for generated PDF exports.
2. Apply the same style to generated XLSX exports.
3. Keep the style rules in Export-Style-Guide.md as implementation source of truth.
4. Use XLSX-Observed-Profile.md for concrete template metadata.

## Adding New Samples

When adding new reference files:
1. Keep original filenames if they are already used in docs.
2. Add new files with clear program and term naming.
3. Keep both PDF and XLSX when possible for each program.
4. Prefer PNG for focused visual snippets.
