# Scheduling Workflow (Super Admin)

## 1. Pre-Generation Readiness

1. Confirm active academic term.
2. Confirm sections are complete and correctly tagged.
3. Confirm teacher availability and subject assignments.
4. Confirm venues and restrictions are up to date.
5. Confirm curriculum and subject metadata consistency.

## 2. Generation Run

1. Choose generation scope.
2. Select regeneration mode if re-running.
3. Start deterministic generation job.
4. Wait for job status to complete.

## 3. Review Stage

1. Inspect unscheduled subjects.
2. Inspect conflicts by severity and count.
3. Validate section, teacher, and venue views.
4. Mark review notes for unresolved blockers.

## 4. Resolution Stage

1. Resolve high-severity conflicts first.
2. Correct source constraints where necessary.
3. Re-run generation for affected scope.
4. Re-validate diagnostics.

## 5. Publication Stage

1. Verify zero hard conflicts.
2. Verify expected coverage for sections and subjects.
3. Publish official schedule set.
4. Confirm publication timestamp and actor log.

## 6. Post-Publish Monitoring

1. Track reported schedule issues.
2. Apply controlled fixes through regeneration rules.
3. Keep publication history complete.
