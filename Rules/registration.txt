 [1] STUDENT TYPE DEFINITIONS & CHARACTERISTICS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 ┌─────────────────────────────────────────────────────────────────────────────┐
 │ FRESH STUDENT                                                               │
 ├─────────────────────────────────────────────────────────────────────────────┤
 │                                                                             │
 │ DEFINITION:                                                                 │
 │ A first-year, first-semester student with NO academic history yet.          │
 │                                                                             │
 │ DETECTION CRITERIA:                                                         │
 │  • Student number year matches current academic year                        │
 │  • Current active term is "1st Semester"                                    │
 │  • No prior grades in university portal                                     │
 │                                                                             │
 │ CHARACTERISTICS:                                                            │
 │  ✅ Automatically classified as REGULAR                                     │
 │  ✅ Automatically assigned to Year Level 1                                  │
 │  ✅ No academic history import required                                     │
 │  ✅ No prerequisite validation needed                                       │
 │  ✅ No standing evaluation required                                         │
 │  ✅ Follows block section enrollment (fixed section)                        │
 │  ✅ Enrolled in ALL subjects of assigned section                            │
 │  ✅ Must carry full academic load (typically 24 units for BSIT 1Y-1S)       │
 │  ✅ Eligible for academic honors (if criteria met)                          │
 │  ✅ NSTP included in enrollment (not in schedule grid)                      │
 │  ✅ Saturday blocked (NSTP day, no regular classes)                         │
 │                                                                             │
 │ EXAMPLE:                                                                    │
 │  Student Number  : 2025309289                                               │
 │  Email           : 2025309289@pampangastateu.edu.ph                         │
 │  Current Term    : 1st Semester 2025-2026                                  │
 │  Year Level      : 1 (auto-assigned)                                        │
 │  Standing        : REGULAR (auto-assigned)                                  │
 │  Section         : BSIT 1-A (selected via LOI)                              │
 │  Subjects        : 8 subjects / 24 units (full load)                        │
 │  Academic History: Not Applicable                                           │
 │                                                                             │
 │ ENROLLMENT FLOW:                                                            │
 │  1. Google Sign-In (PSU email only)                                         │
 │  2. Profile Completion                                                      │
 │  3. Auto-Classification (no import needed)                                  │
 │  4. Wait for Schedule Publication                                           │
 │  5. Select section and generate printable advising form                     │
 │  6. Submit printed advising form (hard copy) directly to main campus        │
 │  7. Main campus processes official enrollment outside GRADUS                │
 │  8. Enrollment Complete                                                     │
 │                                                                             │
 └─────────────────────────────────────────────────────────────────────────────┘

 ┌─────────────────────────────────────────────────────────────────────────────┐
 │ REGULAR STUDENT (CONTINUING)                                                │
 ├─────────────────────────────────────────────────────────────────────────────┤
 │                                                                             │
 │ DEFINITION:                                                                 │
 │ A continuing student who PASSED ALL subjects every semester and follows     │
 │ the standard curriculum flow with NO back subjects.                         │
 │                                                                             │
 │ DETECTION CRITERIA:                                                         │
 │  • Has academic history (imported from portal)                              │
 │  • All required lower-year subjects are PASSED                              │
 │  • No failed subjects in academic record                                    │
 │  • Standing evaluation result = REGULAR                                     │
 │                                                                             │
 │ CHARACTERISTICS:                                                            │
 │  ✅ Must import all completed semesters from portal                         │
 │  ✅ System evaluates standing based on pass/fail record                     │
 │  ✅ Follows block section enrollment (fixed section)                        │
 │  ✅ Assigned to ONE section only                                            │
 │  ✅ Enrolled in ALL subjects of that section (full load)                    │
 │  ✅ No subject-by-subject selection                                         │
 │  ✅ No time conflict checking needed (section pre-validated)                │
 │  ✅ Prerequisite validation automatic (all passed)                          │
 │  ✅ Eligible for academic honors (Dean's/President's List)                  │
 │  ✅ No advance subject taking                                               │
 │  ✅ No back subject retaking                                                │
 │                                                                             │
 │ EXAMPLE:                                                                    │
 │  Student Number  : 2021301234                                               │
 │  Email           : 2021301234@pampangastateu.edu.ph                         │
 │  Current Term    : 4th Year 2nd Semester 2024-2025                         │
 │  Year Level      : 4 (evaluated from history)                               │
 │  Standing        : REGULAR (all subjects passed)                            │
 │  Section         : BSIT 4-A (selected via LOI)                              │
 │  Subjects        : 6 subjects / 21 units (full load)                        │
 │  Academic History: 51 subjects completed, all passed                        │
 │  GWA (Previous)  : 1.45 (eligible for honors)                               │
 │                                                                             │
 │ ENROLLMENT FLOW:                                                            │
 │  1. Google Sign-In (PSU email only)                                         │
 │  2. Profile Completion                                                      │
 │  3. Academic History Import (via Mobile WebView)                            │
 │  4. Standing Evaluation (system checks all subjects → REGULAR)              │
 │  5. Wait for Schedule Publication                                           │
 │  6. Select section and generate printable advising form                     │
 │  7. Submit printed advising form (hard copy) directly to main campus        │
 │  8. Main campus processes official enrollment outside GRADUS                │
 │  9. Enrollment Complete                                                     │
 │                                                                             │
 └─────────────────────────────────────────────────────────────────────────────┘

 ┌─────────────────────────────────────────────────────────────────────────────┐
 │ IRREGULAR STUDENT                                                           │
 ├─────────────────────────────────────────────────────────────────────────────┤
 │                                                                             │
 │ DEFINITION:                                                                 │
 │ A continuing student who FAILED one or more subjects in a previous          │
 │ semester, causing deviation from the standard curriculum flow.              │
 │                                                                             │
 │ DETECTION CRITERIA:                                                         │
 │  • Has academic history (imported from portal)                              │
 │  • Has at least ONE failed subject                                          │
 │  • Not all required lower-year subjects are passed                          │
 │  • Standing evaluation result = IRREGULAR                                   │
 │                                                                             │
 │ CHARACTERISTICS:                                                            │
 │  ✅ Must import all completed semesters from portal                         │
 │  ✅ System evaluates standing based on pass/fail record                     │
 │  ✅ Has BACK SUBJECTS (failed subjects to retake)                           │
 │  ✅ Has BLOCKED SUBJECTS (due to failed prerequisites)                      │
 │  ✅ NO ADVANCE SUBJECT TAKING (must follow current curriculum progression)   │
 │  ✅ NO fixed section assignment                                             │
 │  ✅ Subject-by-subject enrollment across different sections                 │
 │  ✅ Time conflict checking required (cross-section enrollment)              │
 │  ✅ Prerequisite validation per subject                                     │
 │  ✅ Unit load cap enforced (maximum 23 units per semester)                  │
 │  ✅ NOT eligible for academic honors                                        │
 │  ✅ System generates recommended enrollment plan                            │
 │  ✅ Student prints advising form and submits hard copy to main campus       │
 │  ✅ Appears in multiple section class lists                                 │
 │                                                                             │
 │ EXAMPLE:                                                                    │
 │  Student Number  : 2023309289                                               │
 │  Email           : 2023309289@pampangastateu.edu.ph                         │
 │  Current Term    : 2nd Year 2nd Semester 2025-2026                         │
 │  Year Level      : 2 (last completed year)                                  │
 │  Standing        : IRREGULAR                                                │
 │  Reason          : Failed CC 213(D) and ITELEC 1 in 2Y-1S                  │
 │  Back Subjects   : 2 (CC 213(D), ITELEC 1)                                  │
 │  Blocked Subjects: 5 (due to failed prerequisites)                          │
 │  Section         : None (cross-section enrollment)                          │
 │  Subjects        : 6 subjects / 17 units (variable load)                    │
 │  Academic History: 19 subjects completed, 2 failed                          │
 │                                                                             │
 │ ENROLLMENT FLOW:                                                            │
 │  1. Google Sign-In (PSU email only)                                         │
 │  2. Profile Completion                                                      │
 │  3. Academic History Import (via Mobile WebView)                            │
 │  4. Standing Evaluation (system detects failed subjects → IRREGULAR)        │
 │  5. Wait for Schedule Publication                                           │
 │  6. Generate Enrollment Plan (system runs algorithm)                        │
 │  7. Review Generated Plan (student sees recommended schedule)               │
 │  8. Print Advising Form                                                     │
 │  9. Submit printed advising form (hard copy) directly to main campus        │
 │  10. Main campus processes official enrollment outside GRADUS               │
 │  11. Enrollment Complete                                                    │
 │                                                                             │
 └─────────────────────────────────────────────────────────────────────────────┘

 ┌─────────────────────────────────────────────────────────────────────────────┐
 │ TRANSFEREE STUDENT                                                          │
 ├─────────────────────────────────────────────────────────────────────────────┤
 │                                                                             │
 │ DEFINITION:                                                                 │
 │ A student transferring from another school or another department/program    │
 │ within PSU whose academic records are NOT available in the PSU evaluation   │
 │ portal and therefore cannot be imported via mobile WebView.                 │
 │                                                                             │
 │ DETECTION CRITERIA:                                                         │
 │  • Student is not classified as Fresh                                       │
 │  • PSU portal returns no importable evaluation records                      │
 │  • OR student self-identifies as transferee during profile completion       │
 │                                                                             │
 │ CHARACTERISTICS:                                                            │
 │  ✅ Cannot be auto-classified by the system                                 │
 │  ✅ No automated advising plan generation                                   │
 │  ✅ No standing evaluation possible without portal data                     │
 │  ✅ System blocks enrollment flow and shows main campus redirect message    │
 │  ❌ NOT eligible for academic honors until properly classified              │
 │                                                                             │
 │ SYSTEM ACTION:                                                              │
 │  standing_status          = 'transferee'                                    │
 │  academic_history_status  = 'not_applicable_transferee'                     │
 │  Show message: "Your academic records could not be found in the PSU        │
 │  evaluation portal. Please contact main campus directly for subject        │
 │  equivalency evaluation and enrollment assistance."                        │
 │                                                                             │
 │ MAIN CAMPUS ACTION (outside GRADUS):                                        │
 │  • Evaluate subject equivalencies from previous institution or program      │
 │  • Determine year level placement                                           │
 │  • Process official enrollment                                              │
 │                                                                             │
 │ ENROLLMENT FLOW:                                                            │
 │  1. Google Sign-In (PSU email only)                                         │
 │  2. Profile Completion                                                      │
 │  3. System detects no importable portal records → flags as TRANSFEREE       │
 │  4. System displays main campus redirect message                            │
 │  5. Student contacts main campus directly                                   │
 │  6. Main campus evaluates equivalencies and processes enrollment            │
 │  8. Enrollment Complete                                                     │
 │                                                                             │
 └─────────────────────────────────────────────────────────────────────────────┘

 TRIGGERED AFTER PROFILE COMPLETION
 ┌─────────────────────────────────────────────────────────────────────────────┐
 │                                                                             │
 │  STEP 1: Extract year from student number                                  │
 │  ──────────────────────────────────────────────────────────────────────    │
 │  Student Number: 2025309289                                                 │
 │  Extracted Year: 2025                                                       │
 │                                                                             │
 │  STEP 2: Check if active academic term exists                              │
 │  ──────────────────────────────────────────────────────────────────────    │
 │  Query:                                                                     │
 │    SELECT * FROM academic_terms WHERE is_active = true LIMIT 1             │
 │                                                                             │
 │  IF (no active term found):                                                 │
 │    ├─ academic_history_status = "pending_term"                              │
 │    ├─ standing_status = NULL                                                │
 │    ├─ current_year_level = NULL                                             │
 │    ├─ Show "Waiting for enrollment period" message                          │
 │    ├─ OPTIONALLY allow grade import (saved but not evaluated)               │
 │    └─ EXIT (wait for Super Admin to activate term)                          │
 │                                                                             │
 │  ELSE (active term exists):                                                 │
 │    └─ PROCEED to STEP 3                                                     │
 │                                                                             │
 │  STEP 3: Get current active academic term details                          │
 │  ──────────────────────────────────────────────────────────────────────    │
 │  Active Term: 1st Semester 2025-2026                                        │
 │  Term Year  : 2025                                                          │
 │  Semester   : 1st                                                           │
 │                                                                             │
 │  STEP 4: Apply detection rules                                             │
 │  ──────────────────────────────────────────────────────────────────────    │
 │                                                                             │
 │  RULE A: FRESH STUDENT DETECTION                                            │
 │  ───────────────────────────────────────────────────────────────────────   │
 │  IF (student_number_year == current_term_year)                              │
 │     AND (current_semester == "1st Semester")                                │
 │  THEN                                                                       │
 │    student_type = "FRESH"                                                   │
 │    academic_history_status = "not_applicable"                               │
 │    standing_status = "regular"                                              │
 │    current_year_level = 1                                                   │
 │    SKIP academic history import                                             │
 │    PROCEED to advising form and section selection flow                      │
 │    EXIT                                                                     │
 │                                                                             │
 │  RULE B: CONTINUING STUDENT DETECTION                                       │
 │  ───────────────────────────────────────────────────────────────────────   │
 │  ELSE                                                                       │
 │    student_type = "CONTINUING"                                              │
 │    academic_history_status = "incomplete"                                   │
 │    standing_status = NULL (to be evaluated after import)                    │
 │    current_year_level = NULL (to be evaluated after import)                 │
 │    REQUIRE academic history import from portal                              │
 │                                                                             │
 │    IF import attempt returns no records from portal:                        │
 │      → APPLY RULE C: TRANSFEREE DETECTION                                   │
 │                                                                             │
 │    AFTER successful import completion:                                      │
 │    RUN standing evaluation (STEP 5)                                         │
 │                                                                             │
 │  RULE C: TRANSFEREE DETECTION                                               │
 │  ───────────────────────────────────────────────────────────────────────   │
 │  IF (student is not FRESH)                                                  │
 │     AND (PSU portal returns no importable evaluation records)               │
 │     OR  (student self-identifies as transferee at profile completion)       │
 │  THEN                                                                       │
 │    student_type = "TRANSFEREE"                                              │
 │    academic_history_status = "not_applicable_transferee"                    │
 │    standing_status = "transferee"                                           │
 │    current_year_level = NULL                                                │
 │    BLOCK automated advising plan generation                                 │
 │    SHOW redirect message → contact main campus directly                      │
 │    EXIT (main campus handles placement outside GRADUS)                      │
 │                                                                             │
 │  STEP 5: STANDING EVALUATION (CONTINUING STUDENTS ONLY)                    │
 │  ──────────────────────────────────────────────────────────────────────    │
 │                                                                             │
 │  INPUT:                                                                     │
 │    student_id: 2023309289                                                   │
 │    program: BSIT                                                            │
 │    imported_grades: student_subject_completions table                       │
 │                                                                             │
 │  PROCESS:                                                                   │
 │    1. Determine expected year level from latest term_taken                  │
 │    2. Fetch all required subjects for that year level                       │
 │    3. Check pass/fail status for each required subject                      │
 │                                                                             │
 │  EVALUATION LOGIC:                                                          │
 │                                                                             │
 │    IF (all required lower-year subjects are PASSED)                         │
 │    THEN                                                                     │
 │      standing_status = "regular"                                            │
 │      current_year_level = computed from curriculum                          │
 │      PROCEED to LOI enrollment flow                                         │
 │                                                                             │
 │    ELSE (at least one subject FAILED)                                       │
 │      standing_status = "irregular"                                          │
 │      current_year_level = last successfully completed year                  │
 │      PROCEED to plan-based enrollment flow                                  │
 │                                                                             │
 │  EXAMPLE EVALUATION:                                                        │
 │  ───────────────────────────────────────────────────────────────────────   │
 │                                                                             │
 │  Student: 2023309289                                                        │
 │  Latest term_taken: 2024-2025 1st Semester (2Y-1S)                         │
 │  Expected next: 2Y-2S                                                       │
 │                                                                             │
 │  Required subjects check:                                                   │
 │    1Y-1S (8 subjects) → ✅ All PASSED                                       │
 │    1Y-2S (8 subjects) → ✅ All PASSED                                       │
 │    2Y-1S (8 subjects) → ❌ 2 FAILED (CC 213(D), ITELEC 1)                  │
 │                                                                             │
 │  Result:                                                                    │
 │    standing_status = "irregular"                                            │
 │    current_year_level = 2                                                   │
 │    reason = "Failed 2 subjects in 2Y-1S"                                    │
 │                                                                             │
 └─────────────────────────────────────────────────────────────────────────────┘
